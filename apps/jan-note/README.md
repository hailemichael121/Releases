## 📋 Features

- **Rich Quill Editor:** Full-featured rich text editing with bold, italic, headings, lists, quotes, and alignments.
- **Auto-Save & Offline Storage:** All notes and attachments stored locally in Hive DB with zero cloud dependence.
- **Smart Verse & Tag Detection:** Automatically tags scriptural references and canonical study topics.
- **Distraction-Free Reading Mode:** Clean full-screen reading experience for study sessions.
- **Tutorial & Onboarding:** First-run interactive flow with sample notes.
